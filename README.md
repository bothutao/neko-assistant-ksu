# 猫娘助手 (Neko Assistant KSU)

本项目是一个专为 Android KernelSU 及其分支设计的 WebUI AI 模块。通过接入 DeepSeek API，实现与本地设备的深度交互。在 v2.0.0 中，猫娘助手从“对话助手”进化为具备系统级操作能力的 **多模态 Agent**。

## 兼容性声明

本项目遵循通用的 Android Root 模块目录规范（`/data/adb/modules/neko`），通过标准 Shell 指令与 Root 权限交互。理论**兼容 KernelSU 及其所有衍生分支**，不依赖任何特定管理器的闭源私有 API。

## 核心特性

### 1. 多模型智能路由与思考控制
- 支持 `deepseek-flash` 与 `deepseek-v4-pro` 两个核心模型。
- **Auto 模式**：系统会根据输入内容和附件情况，自动判断并路由到最合适的模型，平衡速度与深度。
- **思考等级调节**：在 Flash 和 Pro 按钮上支持切换思考深度（N: None, L: Low, H: High, M: Max），以控制模型推理时的 Token 消耗和响应速度。

### 2. Agent 系统操控（v2.0.0 新增）
- **双引擎读屏**：`read_ui` 用于快速抓取标准无障碍树节点；`read_ocr` 调用本地 Tesseract 引擎，离线识别 WebView、游戏等非标界面中的文字及坐标。两者互补，避免单一方案在复杂场景下失效。
- **执行层工具**：新增 `tap_screen`（坐标点击）、`swipe_screen`（滑动）、`press_key`（模拟物理按键）与 `input_text`（基于 YADB 键盘服务实现原生中文注入，不经过系统剪贴板）。
- **权限沙盒**：Agent 模式下（长按授权后）拥有最高执行权限，系统命令直接运行；非 Agent 模式保留命令安全审查，高危操作仍需手动确认。

### 3. 多模态与文档解析
- **图像识别**：支持发送多张图片，自动路由至视觉模型（`deepseek-flash`）进行分析。
- **文档提取**：支持上传 `.txt`, `.md`, `.json`, `.csv`, `.py` 等纯文本文件。
- **Office 解析**：集成 `officeparser` 库，支持读取 `.docx`, `.pptx`, `.xlsx`, `.pdf` 等格式的文本内容供模型阅读。

### 4. 原生工具调用 (Tool Calls)
- `search`：获取实时互联网信息。
- `fetch_url`：抓取指定 URL 的网页纯文本内容进行深度阅读。
- `execute_command`：执行 Android Shell 命令。

### 5. 长期记忆系统 (Memory)
- `write_memory`：记录用户偏好和重要信息，强制采用“关键词/标签”格式以节省 Token。
- `search_memory`：基于关键词匹配或读取最近记录，检索长期记忆。
- `delete_memory`：基于精确的时间戳抹除指定记忆。

### 6. 高级渲染与排版
- 采用 `markdown-it` 引擎替换原生渲染，完美支持复杂表格。
- 集成 `KaTeX` 与 `mhchem`，完美渲染数学公式与化学方程式。
- 集成 `Mermaid`，支持将代码块渲染为流程图、时序图等图表。
- 提供 HTML 代码块的沙盒隔离预览功能。

### 7. 底层架构与运行保障
- **数据隔离**：配置文件与聊天历史存放于 `/data/adb/neko/` 目录下，不受模块更新或刷机影响。
- **智能休眠中断防御（音频保活说明）**：
  - **重要提示：本模块不会在后台长期播放音乐。**
  - 为防止 Android 系统将处于后台的 WebView 冻结（导致执行中断），在 Agent 任务执行期间，前端会通过 Web Audio API 注入极微弱的正弦波（音量 0.001）。
  - 该音频**仅在任务执行期间生效**，任务完成或手动中止后会立刻销毁音频引擎释放资源，不会造成后台耗电。
- **长文本读取优化**：针对 `ksu.exec` 的截断问题，采用 `sed` 逐行读取拼接的方案，确保大体积历史记录与命令输出完整无损。

## 安装方法
1. 在 Releases 页面下载最新的 `.zip` 模块包。
2. 打开 KSU 管理器，进入模块页面，选择下载的 zip 包并刷入。
3. 重启设备。

## 配置说明
首次开机后，系统会自动在 `/data/adb/neko/` 目录下生成 `config.conf` 配置文件。请使用具有 Root 权限的文件管理器（如 MT 管理器）编辑该文件，填入你的 `API_KEY`。
