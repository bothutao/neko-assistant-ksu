# 猫娘助手 (Neko Assistant KSU)

本项目是一个专为 Android Root 环境（目前主要适配 SukiSU）设计的 WebUI AI 模块。通过接入大模型 API，实现与本地设备的深度交互，同时具备系统级操作能力的多模态 Agent。

## 兼容性声明

本项目遵循通用的 Android Root 模块目录规范（`/data/adb/modules/neko`），通过标准 Shell 指令与 root 权限交互。

**理论上兼容 KernelSU 及其所有衍生分支，但目前仅在开发者个人的 SukiSU 环境下完成了完整的实机测试与验证。** 若您使用其他管理器，请自行测试。

## 核心特性

### 1. 多模态环境感知与系统操控
- **极速视觉 (`view_image`)**：截取全屏后直接以多模态形式交给主模型，跳过繁琐的中间描述环节，速度更快，分析更准。
- **双引擎读屏**：`read_ui` 用于快速抓取标准无障碍树节点；遇到 WebView 或游戏界面时，自动降级调用本地 `read_ocr`（基于 Tesseract），离线提取文字与坐标。
- **执行层工具**：支持 `tap_screen`（坐标点击）、`swipe_screen`（滑动）、`press_key`（模拟物理按键）与 `input_text`（基于 YADB 原生注入，支持中文输入）。
- **权限沙盒**：Agent 模式下（长按授权后）拥有最高执行权限，系统命令直接运行；非 Agent 模式保留命令安全审查，高危操作仍需手动确认。

### 2. 多模型智能路由与思考控制
- 支持分配多个模型。**Auto 模式** 会根据输入内容和附件情况，自动判断并路由到最合适的模型。
- **思考等级调节**：支持在面板切换思考深度（N: None, L: Low, H: High, M: Max），以控制模型推理时的 Token 消耗和响应速度。

### 3. 自动化与文件解析
- **图像与文档**：支持发送多张图片，自动路由至视觉模型；集成 `officeparser` 库，支持读取 `.docx`, `.pptx`, `.xlsx`, `.pdf` 等格式的文本内容。
- **原生工具调用**：具备 `search` (联网搜索)、`fetch_url` (网页抓取)、`execute_command` (执行命令) 能力。
- **长期记忆**：`write_memory` 记录偏好，`search_memory` 多词检索去重，`delete_memory` 精准遗忘。

### 4. 高级渲染与界面
- 采用 `markdown-it` 引擎，完美支持复杂表格、`KaTeX` 数学公式与 `Mermaid` 流程图。
- 提供 HTML 代码块的沙盒隔离预览，并支持一键全屏查看。
- UI 支持根据系统时间自动在白天与黑夜模式间切换。

### 5. 底层架构与运行保障
- **数据隔离**：配置文件与聊天历史存放于 `/data/adb/neko/` 目录下，不受模块更新影响。
- **智能休眠中断防御（音频保活说明）**：
  - **重要提示：本模块不会在后台长期播放音乐。**
  - 为防止 Android 系统将处于后台的 WebView 冻结，在 Agent 任务执行期间，前端会通过 Web Audio API 注入极微弱的正弦波（音量 0.001）。
  - 该音频仅在任务执行期间生效，任务完成或手动中止后会立刻销毁音频引擎释放资源，不会造成后台耗电。
- **长文本与执行防卡死**：针对 `ksu.exec` 的截断问题，全面采用 `sed` 逐行读取与让出主线程机制，确保大体积历史记录与命令输出完整无损。

## 安装与配置

1. 在 Releases 页面下载最新的 `.zip` 模块包。
2. 打开你的 Root 管理器（如 SukiSU），进入模块页面，刷入该 zip 包并重启设备。
3. 首次开机后，系统会自动在 `/data/adb/neko/` 目录下生成 `config.conf`。请使用具有 Root 权限的文件管理器编辑该文件，填入你的 `API_KEY`、`API_URL` 以及模型名称。
4. **依赖准备**：由于涉及高级 Agent 功能，请确保模块的 `bin/` 目录下包含 `yadb` 和 `tesseract` 二进制文件，并在 `tessdata/` 目录下放置对应的语言包（如 `chi_sim.traineddata`）。
